概述

ALPHA LIVE 是一款 Chrome 侧边栏扩展，用于实时展示公开的 DEX Screener Token Profile 信息，并为用户提供前往第三方交易平台、项目网站及社交页面的快捷入口。

我们不要求注册账户，不运营用于接收扩展数据的后端服务器，也不会收集、出售或出租用户的个人信息。

扩展处理的数据

公开 Token Profile 数据

扩展会直接连接 DEX Screener 的公开服务，接收链标识、代币合约地址、项目名称或符号、图标、简介、网站及社交链接等公开信息。这些信息仅用于在侧边栏中实时展示，并临时保存在扩展页面的内存中；关闭或重新加载侧边栏后会被清除。

本地已读状态

当用户将事件标记为已读时，扩展会在浏览器本地存储中保存用于识别该公开事件的标记。数据不会由 ALPHA LIVE 的开发者接收或同步。用户可通过清除扩展数据或卸载扩展删除这些本地记录。

剪贴板

只有在用户主动点击代币合约地址时，扩展才会将该地址写入剪贴板。扩展不会读取剪贴板内容。

网络连接与第三方服务

扩展会连接 DEX Screener 获取实时公开数据，并可能加载 Token Profile 中提供的公开图片。和普通网站访问一样，这些第三方服务可能接收到 IP 地址、浏览器类型及必要的网络请求信息，其处理方式受各自隐私政策约束。

用户主动点击按钮后，可能会打开 DEX Screener、GMGN、Binance Web3、DeBot、OKX Web3、项目网站或社交平台。ALPHA LIVE 不控制这些网站的数据处理行为。

返佣链接披露

部分交易平台链接包含推荐或返佣标识。用户通过这些链接访问或使用第三方服务时，ALPHA LIVE 的运营者可能获得佣金。是否点击或使用这些链接完全由用户决定，返佣关系不会改变扩展展示的公开 Token Profile 数据。

我们不收集的数据

ALPHA LIVE 不收集姓名、邮箱、电话号码、精确位置、浏览历史、钱包私钥、助记词、登录凭据、支付信息或交易授权信息，也未集成广告、用户行为分析或跨站跟踪服务。

权限用途

  • sidePanel：用于在 Chrome 侧边栏中显示实时监控界面。
  • api.dexscreener.com 主机权限：仅用于直接连接 DEX Screener 并接收公开 Token Profile 数据。

数据共享与保留

我们不会向任何第三方出售或转让用户个人数据。扩展不向开发者服务器上传信息。公开 Token Profile 数据仅在当前扩展页面运行期间保留，本地已读标记会一直保留，直至用户清除扩展数据或卸载扩展。

政策更新

如果扩展功能或数据处理方式发生变化，我们会更新本页面及顶部生效日期。重大变化可能同时通过 Chrome Web Store 的版本说明进行提示。

联系我们

如对本隐私政策有疑问，请通过 ALPHA LIVE GitHub Issues 联系我们。

ALPHA LIVE 仅提供公开信息监控和第三方链接入口，不提供投资建议、资产托管或交易执行服务。数字资产交易存在风险。

Overview

ALPHA LIVE is a Chrome side panel extension that displays public DEX Screener Token Profile information in real time and provides shortcuts to third-party trading platforms, project websites, and social pages.

We do not require an account, operate a backend server that receives extension data, or collect, sell, or rent users' personal information.

Data processed by the extension

Public Token Profile data

The extension connects directly to DEX Screener's public service and receives public information such as chain identifiers, token contract addresses, project names or symbols, icons, descriptions, websites, and social links. This information is used only for display in the side panel and is held temporarily in the extension page's memory. It is cleared when the side panel is closed or reloaded.

Local read status

When a user marks an event as read, the extension stores a marker identifying that public event in the browser's local storage. This data is not received or synchronized by the ALPHA LIVE developer. Users can remove it by clearing extension data or uninstalling the extension.

Clipboard

The extension writes a token contract address to the clipboard only after the user clicks that address. It does not read clipboard contents.

Network connections and third parties

The extension connects to DEX Screener for real-time public data and may load public images supplied in Token Profiles. As with normal website access, those third parties may receive an IP address, browser type, and network request information required to provide their services. Their own privacy policies govern that processing.

After a user clicks a button, the extension may open DEX Screener, GMGN, Binance Web3, DeBot, OKX Web3, project websites, or social platforms. ALPHA LIVE does not control how those websites process data.

Affiliate link disclosure

Some trading-platform links contain referral or affiliate identifiers. The ALPHA LIVE operator may receive a commission if a user visits or uses a third-party service through those links. Clicking and using these services is optional, and affiliate relationships do not alter the public Token Profile data displayed by the extension.

Data we do not collect

ALPHA LIVE does not collect names, email addresses, phone numbers, precise locations, browsing history, wallet private keys, seed phrases, login credentials, payment information, or transaction authorization data. It does not include advertising, behavioral analytics, or cross-site tracking services.

Permission usage

  • sidePanel: Displays the real-time monitoring interface in Chrome's side panel.
  • api.dexscreener.com host permission: Used only to connect directly to DEX Screener and receive public Token Profile data.

Sharing and retention

We do not sell or transfer users' personal data to third parties. The extension does not upload information to a developer-operated server. Public Token Profile data remains only while the current extension page is running. Local read markers remain until the user clears extension data or uninstalls the extension.

Changes to this policy

If extension features or data practices change, we will update this page and the effective date above. Material changes may also be identified in Chrome Web Store release notes.

Contact

For questions about this policy, contact us through ALPHA LIVE GitHub Issues.

ALPHA LIVE provides public-information monitoring and links to third parties. It does not provide investment advice, asset custody, or trade execution. Digital asset trading involves risk.
